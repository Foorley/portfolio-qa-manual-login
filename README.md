# Portfólio QA Manual — Testes de Login

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de QA (Quality Assurance) e testes manuais de software, utilizando uma aplicação pública de demonstração de login.

Durante a prática, foram elaborados e executados casos de teste para verificar o comportamento do sistema em diferentes situações de autenticação.

## Objetivo

Validar o comportamento da funcionalidade de login, verificando se o sistema permite o acesso com credenciais válidas e bloqueia tentativas com informações incorretas ou campos vazios.

## Ambiente de teste

- **Aplicação:** Practice Test Automation — Practice Test Login
- **URL:** https://practicetestautomation.com/practice-test-login/
- **Tipo de teste:** Teste funcional manual
- **Ferramenta de documentação:** Microsoft Excel
- **Evidências:** Capturas de tela dos resultados dos testes

## Escopo dos testes

Foram trabalhados quatro cenários de autenticação:

| ID | Cenário | Resultado |
|---|---|---|
| CT-001 | Login com credenciais válidas | Passou |
| CT-002 | Login com usuário inválido | Passou |
| CT-003 | Login com senha inválida | Passou |
| CT-004 | Login com campos vazios | Passou |

Os resultados foram registrados conforme o comportamento observado durante a execução dos testes.

## O que foi praticado

- Elaboração de casos de teste.
- Definição de pré-condições e passos de execução.
- Comparação entre resultado esperado e resultado real.
- Registro de status dos testes.
- Documentação de evidências.
- Organização de resultados em planilha.
- Validação de cenários positivos e negativos de login.

## Resultados e aprendizados

A execução dos cenários permitiu praticar a validação de uma funcionalidade de autenticação e a documentação dos resultados encontrados.

O projeto também ajudou a desenvolver familiaridade com a organização de casos de teste, registro de evidências e análise do comportamento esperado de uma aplicação.

## Observação

Este é um projeto pessoal de estudo e prática em QA Manual, realizado em um ambiente público de demonstração. Não representa experiência profissional em QA.
